# **Code and data for Cross-trophic plankton BEF relationships in the Baltic Sea**

### The folders in this repository include:
- *Data:* This folder contains the data used to run the plankton BRM models, which includes plankton monitoring and trait data, and water quality data.

- *Data formatting scripts:* This folder contains the script for cleaning and processing the data to be used in the BRM model, which includes calculating the functional diversity, resource use efficiency, and daylight hours.

- *BRM final 260401:* This folder has the scripts to run all the BRM models on plankton diversity and resource use efficiency, and also the spatial and seasonal variance partitioning of the model. There is also scripts on the figures that are made for the manuscript.

- *Results:* This folder includes the result outputs of the BRM models, including the model comparisons and fitness checks. 

- *Figures:* This is where all the figures used in the manuscript are found.
